INPUT FILES
===========
- TMX current universe: official TSX/TSXV CSV/XLSX/JSON downloaded for the run.
- identity_overrides.csv: optional verified LEI/ISIN/website corrections.
- SEDAR DDS manifest: optional authorized/licensed bulk metadata. It may point to HTTP(S) URLs or local PDF paths.

The *.example.csv files are templates. The SEDAR URL in the example is intentionally non-functional.
